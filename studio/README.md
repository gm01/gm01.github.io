# Quality by Design — 별도 디자인 시안

원본 `../index.html`, `../styles.css`, `../automation.html`은 수정하지 않았습니다.
이 폴더는 기존 사이트와 독립된 HTML/CSS/JS 시안입니다. 현재 시안을 확인하려면 `studio/index.html`을 열거나 저장소 루트에서 정적 서버를 실행한 뒤 `/studio/`로 접속하세요.

- 콘텐츠: `index.html`
- 디자인, 반응형, 인쇄 스타일: `studio.css`
- 퀵·대리 흐름 전환: `studio.js`
- 그래픽: HTML 안의 직접 작성한 SVG. 실제 앱 화면이나 실행 상태가 아닌 개념도입니다.
- 폰트: Pretendard CDN, 연결되지 않으면 시스템 폰트로 대체됩니다.
- 원본과 동일한 확인된 경험만 사용하며 약 2분 단축·초기 약 87초의 측정 조건을 표시합니다.
- 외부 분석기, 추적 스크립트, 개인정보 수집 기능은 추가하지 않았습니다.

GitHub Pages에 게시하려면 이 폴더를 커밋·푸시한 뒤 `https://gm01.github.io/studio/`에서 별도 페이지로 사용할 수 있습니다. 원본 주소는 그대로 유지됩니다. 현재 작업에서는 게시하지 않았습니다.
